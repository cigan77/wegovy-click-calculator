# Calcolatrice penne Wegovy

Strumento per uso professionale che permette di stimare:

- mg per click in base alla penna selezionata
- numero di click necessari per una dose desiderata
- numero di dosi ottenibili da una penna
- durata stimata della penna (in settimane)
- costo per dose, per settimana e per mese

⚠️ Non destinato all’uso diretto da parte del paziente.
Le istruzioni ufficiali raccomandano di **non impostare la dose contando i click**
del selettore della penna.
